StockSense AI is a full-stack financial engineering and machine learning web application engineered for intermediate quantitative analysis, technical trend classification, and next-trading-day closing price projection. The platform provides real-time equity data integration across Indian (NSE/BSE) and International (NASDAQ/NYSE) exchanges with an institutional fintech user interface.

> **EDUCATIONAL DISCLAIMER**: StockSense AI is strictly intended for educational, quantitative, and research purposes. Stock market participation carries substantial risk of loss. The forecasts generated by machine learning models and technical indicators are statistical simulations and do not constitute financial advice or investment recommendations.

## 1. Problem Statement & Motivation

Traditional retail trading interfaces often suffer from:
1. Fragmented tools separating fundamental quotes, technical indicators, and quantitative predictive models.
2. Inaccurate or uncalibrated machine learning representations (e.g., claiming 99% accuracy by using random train/test splits that suffer from time-series lookahead leakage).
3. Complex, cluttered dashboards lacking transparent mathematical rationales for trend ratings.

StockSense AI solves these challenges by combining real-time historical market data, rigorous time-series train/test methodology, multi-factor technical analysis, deterministic natural-language market synthesis, and persistent watchlist tracking.

## 2. Key Objectives & Features

- **Multi-Market Support**: Seamless analysis of Indian stocks (`RELIANCE.NS`, `TCS.NS`, `INFY.NS`, `HDFCBANK.NS`, `ICICIBANK.NS`, `SBIN.NS`) and US equities (`AAPL`, `MSFT`, `NVDA`, `GOOGL`, `AMZN`, `TSLA`, `JPM`).
- **Technical Indicator Suite**:
  - **SMA 20 & SMA 50**: Short and intermediate trend smoothing.
  - **EMA 20**: Exponential moving average weighted for recent volatility.
  - **RSI 14**: Wilder's smoothed momentum oscillator (30/70 thresholds).
  - **MACD (12, 26, 9)**: Convergence/divergence with signal line & histogram bars.
  - **Bollinger Bands (20, 2)**: Standard deviation volatility envelope.
  - **Daily Percentage Returns**: Session-over-session normalized changes.
- **Transparent Trend Classification**: Rule-based taxonomy classifying market structures into **Bullish**, **Bearish**, or **Sideways** with plain-English rationales.
- **Machine Learning Engine**:
  - **Linear Regression**: Baseline multivariate parametric model.
  - **Random Forest Regressor**: Non-linear ensemble model capturing indicator interactions.
  - **Last-Observed-Close Baseline**: Benchmarking models against naive persistence.
  - **Leakage-Free Formulation**: Target shifted by 1 session ($Target_t = Close_{t+1}$), chronological 80/20 train/test split.
  - **Honest Evaluation**: Measured using MAE, RMSE, and Directional Accuracy.
- **Deterministic Natural Language Insights**: Synthesizes moving averages, RSI, MACD, and ML projections into plain-English analytical paragraphs.
- **Persistent Watchlists**: MongoDB integration with automatic fallback to local session/demo mode.
- **Institutional Fintech UI**: Dark navy/charcoal styling, responsive collapsible sidebar, interactive Recharts visualizations, and currency awareness (INR ₹ vs. USD $).

## 5. Machine Learning Methodology

```
Historical OHLCV (2 Years)
          │
          ▼
Technical Indicators & Lag Feature Engineering
(SMA20, SMA50, EMA20, RSI, MACD, Lag_Close_1, Lag_Close_2, Lag_Close_5, Return_Lag_1, Vol_Change)
          │
          ▼
Target Shifting: Target[t] = Close[t + 1] (Strictly avoids lookahead leakage)
          │
          ▼
Chronological Split (80% Train, 20% Test — No random shuffle)
          │
   ┌──────┴──────────────────────────┐
   ▼                                 ▼
Train Models (X_train, y_train)    Evaluate Unseen Test Set (X_test, y_test)
- Linear Regression                - MAE (Mean Absolute Error)
- Random Forest Regressor          - RMSE (Root Mean Squared Error)
- Baseline Persistence             - Directional Accuracy (%)
   │                                 │
   └──────────────┬──────────────────┘
                  ▼
Dynamic Model Selection (Lowest Test RMSE)
Predict Next Trading Day Close using Today's Features X_today
```

## 7. Installation & Setup Guide (Windows & Cross-Platform)

### Prerequisites
- Python 3.10+ (tested on Python 3.14)
- Node.js 18+ (tested on Node v24) & npm
- Optional: MongoDB Community Server (if not installed, demo mode activates automatically)

### Step 1: Clone or Navigate to Directory
```powershell
cd "c:\Users\windows 10\Downloads\StockSense"
```

### Step 2: Backend Setup
```powershell
# 1. Install backend dependencies
python -m pip install -r backend/requirements.txt

# 2. Verify dependencies and run test suite
python backend/tests/test_backend.py

# 3. Start the FastAPI backend server
python -m uvicorn app.main:app --app-dir backend --reload --port 8000
```
The backend API is now live at `http://127.0.0.1:8000`.
- Swagger Documentation: `http://127.0.0.1:8000/docs`
- Redoc Documentation: `http://127.0.0.1:8000/redoc`

### Step 3: Frontend Setup
Open a second terminal window:
```powershell
cd "c:\Users\windows 10\Downloads\StockSense\frontend"

# 1. Install frontend dependencies (if not already installed)
npm install

# 2. Start the Vite React development server
npm run dev
```
Open your browser and navigate to:
`http://localhost:5173`

## 8. API Reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Service health status and database connectivity |
| `GET` | `/api/stocks/search?q={query}` | Search Indian and US stocks by symbol or company name |
| `GET` | `/api/stocks/popular/overview` | Dashboard market overview, gainers, losers, and timestamp |
| `GET` | `/api/stocks/{symbol}` | Current session quote (Price, Change, Open, High, Low, Volume) |
| `GET` | `/api/stocks/{symbol}/history?period={period}` | Historical OHLCV data (`1mo`, `3mo`, `6mo`, `1y`, `5y`) |
| `GET` | `/api/stocks/{symbol}/indicators` | SMA20, SMA50, EMA20, RSI, MACD, Bollinger Bands & Trend |
| `GET` | `/api/stocks/{symbol}/predict` | Next-day closing price prediction, model comparison, actual vs predicted |
| `GET` | `/api/stocks/{symbol}/metrics` | Out-of-sample metrics (MAE, RMSE, Directional Accuracy) |
| `GET` | `/api/stocks/{symbol}/insights` | Deterministic natural-language synthesis |
| `GET` | `/api/watchlist` | Retrieve saved portfolio watchlist |
| `POST` | `/api/watchlist` | Add stock to watchlist (`{"symbol": "AAPL"}`) |
| `DELETE`| `/api/watchlist/{symbol}` | Remove stock from watchlist |

## 10. Verification & Test Suite

The backend includes a dedicated unit test suite in `backend/tests/test_backend.py` covering:
1. `test_01_health_check`: Validates FastAPI operational status.
2. `test_02_stock_search`: Validates ticker discovery for Indian equities (`TCS.NS`).
3. `test_03_stock_quote`: Validates US quotes (`AAPL`) with USD formatting.
4. `test_04_indian_stock_quote`: Validates Indian quotes (`RELIANCE.NS`) with INR formatting.
5. `test_05_stock_history`: Validates OHLCV retrieval and non-empty time-series data.
6. `test_06_technical_indicators`: Validates mathematical computation of SMAs, RSI, and MACD.
7. `test_07_ml_prediction_and_evaluation`: Validates chronological split, Linear Regression, Random Forest, and Directional Accuracy.
8. `test_08_market_insights`: Validates natural-language synthesis.
9. `test_09_watchlist_operations`: Validates CRUD operations with demo mode resilience.
10. `test_10_invalid_symbol_handling`: Validates HTTP 404 rejection on nonexistent symbols.

## 11. Limitations & Future Enhancements

### Limitations
- Stock prices are subject to geopolitical events, macroeconomic surprises, and sentiment shifts that historical price-volume data alone cannot anticipate.
- Free yfinance API endpoints may occasionally face rate limiting under rapid sequential un-cached calls.

### Future Enhancements
- Integration with FinBERT for live news sentiment analysis.
- Multi-step ahead forecasting (e.g., 5-day and 30-day horizons) using LSTM / GRU networks.
- Portfolio backtesting simulation with risk metrics (Sharpe ratio, Maximum Drawdown).
- Real-time WebSockets integration for live streaming tick quotes.
